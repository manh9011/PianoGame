Piano game is a game that can help you learn how to play the piano using falling notes.

Piano game lowers the barrier to entry for beginners. You can get started immediately without knowing how to read sheet music. Playing songs right away provides great motivation to stick with the piano where you can learn traditional sheet music notation over time as you go along, should you choose to.

Piano game is also great for more experienced players. It's a nice platform for quickly sight-reading a new piece, and nearly any song can be found in the MIDI/MusicXML formats that Piano game understands. Piano game is also a nice companion tool for daily practice to complement piano lessons. The scoring and progression systems help keep track of personal growth on each piece.
